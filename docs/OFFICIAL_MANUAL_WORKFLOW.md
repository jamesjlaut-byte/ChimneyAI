# ChimneyAI v33 — Official Manual Workflow

v33 begins the verified-manufacturer-source layer.

## Why this is deliberately restrictive
A generic search result is not enough to establish the controlling manual for an installed appliance. ChimneyAI separates:
1. label identification
2. exact manufacturer
3. exact model
4. official manufacturer source
5. exact installation manual / applicable revision
6. relevant page/instruction
7. field observation
8. professional interpretation

## Initial official-source registry
The initial registry includes official model-driven manual lookup pages for:
- Majestic
- Heat & Glo

The registry is intentionally small. More manufacturers should be added only after their official documentation workflow is verified.

## UI
The Pro interface now includes Official Manual Finder.
When manufacturer + model are present, it:
- shows exact identity to be verified
- links to a known official manufacturer lookup when registered
- gives a five-step verification workflow
- prepares a source-controlled technical question

## Important
v33 does not claim automatic web retrieval inside the running app yet. The current official links are a verified navigation layer. Automatic retrieval, exact PDF matching, revision matching, caching, and source hashing remain next-stage work.
