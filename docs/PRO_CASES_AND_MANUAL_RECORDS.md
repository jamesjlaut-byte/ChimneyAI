# ChimneyAI v34 — saved Pro cases and manual verification records

## Expanded official source registry
v34 includes official manufacturer/support sources for:
- Majestic
- Heat & Glo
- Heatilator
- Regency
- Napoleon

Each registry record includes the official source URL and the date that source workflow was verified during development.

## Manual Verification Record
The technician can now record:
- verified exact model
- exact manual title
- document/part number
- revision
- effective/publication date
- official manufacturer URL
- relevant pages
- verification notes

This is intentionally separate from the AI response. It creates a structured research trail.

## Saved Pro Cases
Pro research setups can be saved locally in the browser:
- manufacturer
- model
- serial
- appliance/fuel type
- technical question
- source state
- manual verification metadata

This allows repeat research on the same appliance without rebuilding context.

### Important limitation
v34 case storage is browser-local only. It is not yet a user account/cloud database. Photos and PDF bytes are not stored inside saved cases.
